# Project progress report through November 4 2026

`NYSE_Closing_Auction_Project_Progress_Report.docx` is the reviewed editable report. `project_progress_report.md` is its text source, and `build_report.py` creates the Word document with python-docx.

The report distinguishes the supplied notebooks and earlier reports from the local reconstruction, verified nonlinear rerun, target comparison, calibration study, and noon/15:30 updates. Figures and numbers in the underlying experiment folders remain the primary numerical evidence.

To rebuild the Word file from the repository root using a Python environment with python-docx installed:

```sh
python reports/project_progress_2026_11_04/build_report.py
```

The final document was rendered and all 14 pages visually reviewed. Rendering tools are not required to read or edit it in Word.
